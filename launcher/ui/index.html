    Desiege is an open-source launcher and runtime patch that makes Dungeon Siege run well on modern Windows, adding native-resolution widescreen, UI scaling, borderless fullscreen and high-frame-rate rendering without modifying any game files.

    Download renderer fix?

    Windows' built-in Direct3D 7 can't render wider than 2048 pixels, so the game crashes at your native resolution. dxwrapper translates the game's Direct3D 7 to Direct3D 9 and fixes that.

    It's a third-party open-source project (zlib licence, ~10 MB). It goes into the launcher's data folder; no game files are changed.
